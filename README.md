# BlinkIT Grocery Data Analysis – Power BI

## Project Overview
This project analyzes BlinkIT grocery data using Microsoft Power BI to understand sales performance, customer preferences, and outlet performance.

## Tools Used
- Microsoft Power BI
- DAX
- Data Visualization

## Key Analysis
- Total Sales and Average Sales
- Average Rating
- Item Type Analysis
- Outlet Size and Location Analysis
- Sales Performance Dashboard

## DAX Measures
```dax
Avg Rating = AVERAGE('BlinkIT Grocery Data'[Rating])

Avg Sales = AVERAGE('BlinkIT Grocery Data'[Sales])
```

## Project File
Open the `.pbix` file using Power BI Desktop to explore the interactive dashboard.
